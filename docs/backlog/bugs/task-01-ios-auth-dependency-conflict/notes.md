# Notes

## Result

The planned downgrade was not needed. With the original pins on `master` (`firebase_core` 5.1.0, `firebase_auth` 7.0.1), `pubspec.lock` resolves `google_sign_in_ios` 6.4.0, which supports Google Sign-In iOS 10. The iOS dependency conflict no longer happens, so `pubspec.yaml` and `CLAUDE.md` are unchanged.

Resolved by Swift Package Manager (`Package.resolved`): `firebase-ios-sdk` 13.1.1, `googlesignin-ios` 10.1.0, `gtm-session-fetcher` 5.3.1. Both tracked `Package.resolved` files were regenerated by the iOS build and added 27 lines each.

## Checks run

- `fvm flutter build ios --debug --no-codesign`: passed.
- `fvm flutter build apk --debug`: passed. A first run failed with `Unresolved reference 'PigeonParser'` in `firebase_auth-7.0.1` because of a stale Gradle cache left by an earlier build with other pins; it passed after deleting `build/` and `android/.gradle`.
- `fvm flutter analyze`: no issues.
- `fvm flutter test`: all 449 tests passed.
