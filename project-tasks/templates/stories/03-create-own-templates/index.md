# STORY 3: Create your own templates

Epic: [Templates](../../index.md)

Status: Provisional. Revisit after Stories 1 and 2 before any implementation.

## User outcome

As a user, I want to save my own workout setups as templates so that I can reuse them with one tap.

## Scope (provisional)

Ideas discussed, none of them approved:

- A "+" icon in the Templates app bar as the entry point, hidden until this story exists. It is not placed on the Start button's corner, which is already used.
- Saving the current values, possibly from the Custom card or the Setup tab.
- Naming, choosing an icon, editing and deleting own templates.
- Where the data lives: on device, per account, or later in a backend.
