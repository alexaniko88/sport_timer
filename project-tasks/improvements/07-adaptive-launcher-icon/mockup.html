Sport Timer app icon: light, dark and tinted

White barbell on brand red by default. iOS 18 gets a dark and a tinted variant, Android gets an adaptive icon with a themed (monochrome) layer. Switch the wallpaper and the tint to see each case. The first two tiles in each band show today's icon for comparison.

Tint

iPhone home screen (iOS 18+)

Light: white on red, opaque. Dark: red barbell, transparent background (iOS draws the dark fill). Tinted: white barbell on black, opaque grayscale; iOS recolors it with the user's tint. The tint control picks that tint.

Android launcher (adaptive icon, Android 8+)

Background layer: solid red. Foreground layer: white barbell inside the 66 dp safe zone, so every launcher shape crops it cleanly. Themed (Android 13+): the launcher draws the monochrome barbell in a color taken from the wallpaper. The tint control stands for that wallpaper color.
